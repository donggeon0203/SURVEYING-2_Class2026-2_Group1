# 측량학(2) 1조 기말 프로젝트

## 연구 주제

**호남권 반도체 메가 클러스터 용수 공급 안정성 진단 및 대체 수자원(저수지·신규 유역) 발굴 종합 분석**

*GEE 기반 장기 수체 시계열(NDWI) 및 지형 유역(DEM) 네트워크 분석을 중심으로*

## 프로젝트 소개

본 프로젝트는 위성영상과 지형 공간자료를 활용하여 호남권 주요 댐의 가뭄 시 수면적 변화를 분석하고, 산업단지 주변의 기존 저수지와 신규 저류지 후보 지역을 탐색하는 것을 목표로 합니다.

## 세부 연구목적

1. **주요 다목적 댐의 장기 수면적 변화 및 가뭄 취약성 분석**
   - Landsat 위성영상과 NDWI를 활용한 수면적 변화 분석

2. **산단 인근 대형 저수지의 수면적 안정성 분석 및 보조 수원 후보지 탐색**
   - 가뭄 시 수면적 유지율, 거리, 고도차 비교

3. **DEM 기반 지형·유역 분석을 통한 신규 저류지 후보지 탐색**
   - 흐름 누적 및 경사도 분석을 통한 지형적 후보지역 검토

## 활용 도구 및 자료

- Google Earth Engine (GEE)
- Google Colab / Python
- Landsat 위성영상 및 NDWI
- DEM (수치표고모델)
- GitHub / GitHub Pages
